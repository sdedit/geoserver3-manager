# geoserver-manager
## Intro
Client library written in Java to interact with [GeoServer] 3.0(http://www.geoserver.org) through its [ReST administration interface](http://docs.geoserver.org/stable/en/user/rest/api/index.html).

The purpose of this project is to apply minimal modifications to the original code in order to make it work with Geoserver 3.0.
